# PanFire Strict Design System Rules

## Visual Rules & Tokens
- Colours: ONLY 4 colours:
  - Cream: `#F3ECDD` (background)
  - Char Black: `#161412` (text, borders, stamps)
  - Oven Red: `#C8371A` (primary actions, accents)
  - Ash Grey: `#8A8378` (secondary text, borders)
- Flat colour only. NO gradients, NO glow, NO soft blur shadows, NO glassmorphism.
- Fonts:
  - Headlines: Fraunces (huge, tight tracking, occasional italic word). Hero headline: clamp(4rem, 12vw, 12rem).
  - Body: Instrument Sans (17-18px).
  - Prices & Meta: JetBrains Mono.
- Borders: 1.5px solid #161412.
- Corners: 0-4px maximum.
- Shadows: Hard offset shadows only (4px 4px 0 #161412) on interactive elements.
- Layout: Deliberately asymmetric 12-column grid. Generous whitespace. Fewer boxes.

## Hard Banned Elements
- Gradients, glow, pill badges, card inside card, 3-icon stat rows, emoji.
- Purple/neon/orange gradients.
- Centered-everything layouts.
- Buzzwords: "Artisanal", "Haute", "Happy Foodies", "100% Hygienic", "Elevate", "Crafted with passion".
- Fake ratings, fake review counts, fake testimonials.
- No pesto drizzle on a Margherita, no fake toggles that do nothing.
